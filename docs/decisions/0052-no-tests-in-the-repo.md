# 0052: No test suite and no token bench in the repository

Status: Accepted
Date: 2026-10-21

## Context

Up to commit `517c07e` the repository held a pytest suite (`tests/`, 577 test functions, about 800 cases, 77 s) with hand-computed expected values for every `norm` calculator, the geometry, the format, the exports and the import, and the token task set (`bench/`) that measured the cost of the CLI's output. Every change had to keep both green. All of it passed at `517c07e`.

The owner judged the suite and the bench to be overhead now that version 1 and version 2 are built and tested: the people who sign check the results, and what looks wrong in a plan or a table is seen by a human.

## Decision

- `tests/` and `bench/` are removed, with pytest and tiktoken from the dev dependencies and the pytest step from CI. Ruff and pyright stay.
- The validation reports in `docs/validation/` keep their test cases as the record of what was verified, and say that the cases passed at `517c07e`.
- The token figures in `README.md` and `ARCHITECTURE.md` §12 stay, as measured at `517c07e` (`bench/results.md`, `bench/agent/results.md` there).
- Everything comes back with `git checkout 517c07e -- tests bench`.

## Alternatives

- **Keep everything.** The safety net for changes, the evidence the validation reports cite, and the only signal an agent gets that it broke something. Rejected as overhead by the owner.
- **Keep only the calculator tests** (about 150, the numbers someone signs) and Haus Müller end to end. Rejected by the owner.
- **Keep the suite, run less of it:** only the touched area locally, the whole suite in CI. Not chosen.

## Consequences

- A change to a calculator, the geometry or the format is no longer checked by code. A wrong number shows up only if the person who checks the result notices it, so the review before signing carries all of it.
- A `norm` calculator changed after `517c07e` is not covered by its validation report's test cases; its report must say so, and the reviewer checks it by hand.
- The cost of the CLI's output for agents is no longer measured.
- `docs/reference.md` is still generated by `uv run python -m uea.reference`, but nothing checks that it is current.
